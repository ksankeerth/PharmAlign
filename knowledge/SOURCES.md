# Document sources

PharmAlign's knowledge library lists the 290 public documents below. **None of them is stored in this repository, and none may be republished from it or from the prototype.** They belong to their publishers, under the publishers' own terms. See [NOTICE](../NOTICE).

The library in the prototype is for showing how the platform works. To read, quote or rely on a document, go to the official source listed here.

## Using the real text

The prototype runs without these files: its demo data has short stand-in text. To try it on the real text of the documents the demo cites:

1. Download each document from its source, following the publisher's terms.
2. Save it as `knowledge/documents/<folder>/<id>__<any-name>.<pdf, html or txt>`. For example, `A-01` in the `UAE_Federal_Laws` folder could be `knowledge/documents/UAE_Federal_Laws/A-01__medicines-law.pdf`. These files stay out of git.
3. Load the demo data with `--with-library`, as the [README](../README.md) describes. A missing file is skipped.

Keep that copy to yourself: a site open to others that shows this text would be republishing it.

32 documents have no direct link. Get those from the issuer's own website.
